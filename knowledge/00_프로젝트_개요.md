# 빌드업 Trading 프로젝트 개요

> 세션 시작 시 참고. 두 계좌의 목적을 혼동하지 않는다.
> (원본: claude.ai 프로젝트 문서 `00_프~1.MD`. 계좌번호는 별칭으로 치환)

이 프로젝트는 국내주식을 "빌드업" 전략으로 매매하는 활동이며, 성격이 다른 두 계좌를 병행 운용한다. 둘 다 궁극적으로는 수익창출을 위한 금융투자 활동이지만, 판단 기준과 성공 지표는 서로 다르다.

## 1. 오리지널 빌드업(오빌) 계좌

- **계좌**: 오빌계좌 (알에프텍 + 오빌 대체종목)
- **목적**: 자금의 파이를 키우는 것
- **방식**: 매일 적립식 매수 + 매월 정해진 투자금 투입. 투자를 멈추지 않는다.
- **기대 효과**: 장기 누적에 따른 눈덩이(복리) 효과
- **판단 기준**: "적립을 멈추지 않는가"가 우선. 비중(%) 개념 없음, 정액 적립 중심.
- 상세 규칙은 `01_오빌_매매_가이드.md` 참고.

## 2. 일반매매(비중매매) 계좌

- **계좌**: 연습계좌 (현재 성호전자 등)
- **목적**: 자금(현금)의 순환
- **방식**: 매매를 끊어가며(사고팔고) 진행. 특정 종목에 물려서 현금흐름이 한 방향으로 고정되지 않도록 회전시킨다.
- **부가 목적**: 실전과 동일한 기준으로 하는 훈련, 시장에 대한 감을 계속 유지
- **판단 기준**: "현금이 순환되고 있는가", 비중(%) 중심 관리
- 상세 규칙은 `02_일반매매_비중_차수_가이드.md` 참고.

## 3. 공통 원칙

- 두 계좌는 별개 트랙이며 규칙을 섞지 않는다 (오빌에는 비중 개념 없음, 일반매매에는 비중 개념 있음).
- 두 활동 모두 결국 수익창출을 위한 것이지만, 오빌은 "장기 확대", 일반매매는 "단기 순환·감각 유지"로 목적이 다르다는 것을 세션마다 기억한다.
- 알에프텍(오빌계좌 내 대규모 평가손실 종목)의 손실을 직접 회복하는 대신, 별도 오빌 대체종목에서 낸 수익으로 알에프텍 상쇄매도 비용을 조금씩 메우는 것이 오빌계좌의 큰 그림이다. 대체종목은 상황에 따라 바뀔 수 있다(성호전자 → 우리기술 등).

## 4. 매매 방식 3가지 유형 (전체 지도)

빌드업 프로젝트 안에서 등장하는 매매 방식은 아래 3갈래로 나뉜다. 각 방식의 세부 규칙은 해당 가이드 파일에서 다룬다.

| 방식 | 핵심 성격 | 상세 가이드 |
|---|---|---|
| 오리지널 빌드업(오빌) / 배정형 빌드업(배빌) / 관리 빌드업(관빌) | 비중 개념 없음, 시간·정액 적립 중심 | `01_오빌_매매_가이드.md` |
| 상추훈련 / 일반매매(비중매매) | 비중(%) 중심, 일 4% 매수 한도 | `02_일반매매_비중_차수_가이드.md` |
| 구간분석·박스권·실전 응용 기법 | 위 두 방식에 공통 적용되는 타점/심리/계좌관리 기법 | `03_매매_기법_및_실전팁.md` |
